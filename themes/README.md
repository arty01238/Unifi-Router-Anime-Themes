# Themes

Each character lives in `themes/<franchise>/<character>/` with a built `.user.css`, a README, and a `preview/` folder. Variants of one character share the folder (see Madoka Kaname).

| Theme | Franchise | Userstyle |
| --- | --- | --- |
| [Ellen Joe](zenless-zone-zero/ellen-joe/) | Zenless Zone Zero | `zenless-zone-zero/ellen-joe/ellen-joe.user.css` |
| [Jane Doe](zenless-zone-zero/jane-doe/) | Zenless Zone Zero | `zenless-zone-zero/jane-doe/jane-doe.user.css` |
| [Madoka Kaname (Light)](madoka-magica/madoka-kaname/) | Puella Magi Madoka Magica | `madoka-magica/madoka-kaname/madoka-kaname-light.user.css` |
| [Madoka Kaname (Dark)](madoka-magica/madoka-kaname/) | Puella Magi Madoka Magica | `madoka-magica/madoka-kaname/madoka-kaname-dark.user.css` |
| [Homura Akemi](madoka-magica/homura-akemi/) | Puella Magi Madoka Magica | `madoka-magica/homura-akemi/homura-akemi.user.css` |

Add a character by editing `src/themes.mjs` and running `npm run build`. The root README has the full steps.
